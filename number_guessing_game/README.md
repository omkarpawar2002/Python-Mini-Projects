# 🎯 Number Guessing Game

A simple command-line Number Guessing Game built using Python. The player tries to guess a secret number, and the program provides hints whether the guess is too high or too low until the correct number is found.

---

## 🚀 Features

- User enters guesses repeatedly
- Secret number matching
- "Too High" hint
- "Too Low" hint
- Attempt counter
- Runs until the correct number is guessed
- Displays total attempts taken

## 🎮 Game Rules

- The secret number is predefined in the program.
- Enter a number to make a guess.
- If the number is smaller than the secret number, the program displays:

```text
Too Low!
```

- If the number is greater than the secret number, the program displays:

```text
Too High!
```

- If the number matches the secret number, the game ends and displays the total attempts taken.
