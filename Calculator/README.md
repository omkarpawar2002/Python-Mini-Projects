# 🧮 Simple Calculator

A basic command-line calculator built using Python. This project performs four fundamental arithmetic operations based on the user's choice and displays the result.

---

## 🚀 Features

- Addition
- Subtraction
- Multiplication
- Division
- Operator selection using menu options
- Division-by-zero handling
- Invalid operator choice handling

---

## 📚 Concepts Used

- Variables
- User Input (`input()`)
- Type Casting (`int()`)
- Arithmetic Operators
- Conditional Statements (`if`, `elif`, `else`)
- Nested `if` Statement
- Output Formatting
