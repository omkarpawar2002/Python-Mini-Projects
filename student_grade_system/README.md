# 🎓 Student Grade System

A simple Python program that takes student marks as input, calculates the corresponding grade, and displays the final result.

---

## 🚀 Features

- Accepts student marks as input
- Calculates grade based on marks
- Displays marks and grade
- Uses multiple conditional statements (`if`, `elif`, `else`)
- Simple and beginner-friendly implementation

---

## 📚 Concepts Used

- Variables
- User Input (`input()`)
- Type Casting (`int()`)
- Conditional Statements (`if`, `elif`, `else`)
- Comparison Operators
- Output Formatting
