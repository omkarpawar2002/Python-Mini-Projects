# 📖 Contact Book

A simple Python console-based Contact Book application that allows users to add, search, update, delete, and manage contacts using dictionaries.

---

## 🚀 Features

- Add new contacts
- Prevent duplicate contacts
- Search contacts by name
- Update contact numbers
- Delete contacts
- View all contacts
- Display total number of contacts
- Case-insensitive contact search

---

## 📚 Concepts Used

- Dictionaries
- Loops (`while`, `for`)
- Conditional Statements (`if`, `elif`, `else`)
- Dictionary Methods
  - `items()`
  - `pop()`
- Membership Operators (`in`, `not in`)
- String Methods (`lower()`)
- User Input
