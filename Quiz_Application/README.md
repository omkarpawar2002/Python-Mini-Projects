# 🧠 Quiz Application

A simple Python console-based Quiz Application that asks multiple-choice questions, checks answers, and calculates the user's score.

---

## 🚀 Features

- Start quiz
- Multiple-choice questions
- Answer validation
- Score calculation
- Show final score
- Menu-driven application
- Exit application safely

---

## 📚 Concepts Used

- Lists
- Dictionaries
- Nested Data Structures
- Loops (`while`, `for`)
- Conditional Statements (`if`, `elif`, `else`)
- User Input
- Score Tracking
