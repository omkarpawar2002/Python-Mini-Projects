# 📦 Inventory Management System

A simple Python console-based Inventory Management System that helps manage products and their stock information using Lists and Dictionaries.

---

## 🚀 Features

- Add new products
- View a particular product
- Remove products from inventory
- View all products
- Update product stock
- Display total products
- Exit application safely

---

## 📚 Concepts Used

- Lists
- Dictionaries
- Nested Data Structures
- Loops (`while`, `for`)
- Conditional Statements (`if`, `elif`, `else`)
- List Methods
  - `append()`
  - `remove()`
- Dictionary Methods
  - `update()`
  - `items()`
- User Input
