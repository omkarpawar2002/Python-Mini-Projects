# 📝 To-Do List

A simple Python console-based To-Do List application that helps users manage tasks using Lists and Dictionaries.

---

## 🚀 Features

- Add new tasks
- Delete tasks using Task ID
- View a particular task
- View all tasks
- Display total number of tasks
- Store task priority
- Store task status
- Exit application safely

---

## 📚 Concepts Used

- Lists
- Dictionaries
- Nested Data Structures
- Loops (`while`, `for`)
- Conditional Statements (`if`, `elif`, `else`)
- List Methods
  - `append()`
  - `remove()`
- Dictionary Methods
  - `update()`
  - `items()`
  - `values()`
- User Input
