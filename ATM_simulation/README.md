# 🏧 ATM Simulation

A simple command-line ATM Simulation built using Python. The program allows users to check their balance, deposit money, withdraw money, and exit the system through a menu-driven interface.

---

## 🚀 Features

- Check Account Balance
- Deposit Money
- Withdraw Money
- Exit ATM System
- Insufficient Funds Validation
- Invalid Amount Validation
- Invalid Menu Choice Handling
- Continuous Menu Using Loops

---

## 📚 Concepts Used

- Variables
- User Input (`input()`)
- Type Casting (`int()`)
- Arithmetic Operators
- Conditional Statements (`if`, `elif`, `else`)
- Nested `if`
- Loops (`while`)
- Infinite Loop (`while True`)
- Loop Control Statement (`break`)
